# Verify event evidence

Run `npm run attribution -- verify-touch --source=<source> --code=<external_id> --evidence="<what was checked>" --actor="<operator>"`. Add `--json` for structured output. Replace angle-bracket values from the operator's records.

Run with --dry-run first, inspect the result, then run without it when the operator has requested the change. Never invent an actor, purpose, date, evidence or amount.
