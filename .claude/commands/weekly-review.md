# Monday attribution review

Run `npm run attribution -- weekly-review`. Add `--json` for structured output. Replace angle-bracket values from the operator's records.

Read the returned records before drawing conclusions. Keep currencies separate and distinguish allocated credit from actual incremental revenue.
Start with channel-credit, unattributed and attention. Then run weekly-review to combine the evidence with spend. State the review period, missing evidence, overdue owner and one action.
