# Why the evidence desk has no front end

The product is a database and commands that review marketing evidence. Views are static, read-only HTML snapshots. Documents are private review packs. They do not collect browser events or update as you watch.

A live application gives shared permissions, interactive exploration, mobile use, continuous collection and immediate updates. This base has none of those. A trusted operator runs it locally. Enterprise DNA builds the required shared screens and connections for the business. Keep existing collection in place while migration is checked.

The models allocate recorded revenue across eligible touches. They do not measure incremental lift. Events are associated by account and optional deal code; there is no probabilistic identity stitching. The same account-level touch can contribute to separate deals, but no model allocates a deal more than once. There is no default foreign exchange rate.
